# Playwright Agents

## Repository Overview
This repository is a Playwright-based test automation project that organizes generated browser tests and supporting test cases in separate folders to make automation workflows easier to manage, review, and execute.

## Prompt used

to generate the test automation and test case, prom stored on test_generation.md 


## Test Automation
Generated by playwright agents fully on /tests


## Test Case
Generated by playwrigh agents fully on /testcase

## Risk Analysis
Post-execution risk scoring, candidate defects and residual risk based on the generated tests: [risk_analysis.md](./risk_analysis.md)
