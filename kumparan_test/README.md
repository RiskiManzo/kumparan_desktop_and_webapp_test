# Kumparan Test

This project is a small web application created as part of a Kumparan technical assessment. The goal is to build a clean, responsive, and user-friendly experience for discovering and reading content while demonstrating solid frontend implementation skills.

## Project Overview

The app focuses on presenting information in a structured and readable way, with attention to usability, layout consistency, and smooth interactions. It is designed to reflect a realistic media/news platform experience, where users can browse content, navigate categories, and consume information efficiently.

## What This Project Demonstrates

- Clear and maintainable UI structure
- Responsive design for multiple screen sizes
- Smooth content browsing experience
- Practical implementation of common product interactions
- Attention to readability, user experience, and code quality

## Note

This project is mostly the work of the user, showcasing personal effort, technical thinking, and implementation skills developed during the task.
